# moa-ugoki ― 行政・社会・議会・世界の動き

MOA の仕事の壁打ちのために、公開されているニュースを毎朝集めて分類するリポジトリです。

- **集めるもの**：省庁の新着、Google ニュース検索（健康・食・文化・地域共生・広島など）、広島県議会と県内23市町（14市・9町）の議会、広島選出の国会議員、世界の主要メディア（アメリカ・中国・欧州・中東・アジア）のトップ記事
- **出力**：`news/latest.md`（直近14日の分類別一覧）、`news/daily/YYYY/YYYY-MM-DD.md`（その日の新着）、`news/db.jsonl`（台帳）
- **動かし方**：GitHub Actions が毎朝6:17（日本時間）に `python3 tools/news.py` を実行して結果をコミットする。Actions 画面の「Run workflow」で手動実行もできる
- **設定**：`news/feeds.json`。集める語は `searches`、注目する議員は `giin`（氏名と役職だけ）に足す

> このリポジトリは公開です。会員の方の情報や団体の内部資料は置かないでください（それらは非公開リポジトリで扱います）。
